Applies to the parts of these files that follow Texas Instruments PDK example
code (PDK 11.02.01.08, ti/drv/ipc/examples/common/src):

  firmware/c66x/src/c66x.c                  cache MAR settings (c66_cache_mar.c)
  firmware/c71x/src/c71x.c                  MMU map (c7x_mmu.c)
  firmware/common/platform/src/ipc_service.c  IPC bring-up sequence (ipc_testsetup.c)
  firmware/common/platform/src/resource_table.c  resource table layout (ipc_rsctable.h)
  firmware/runtime/baremetal/mailbox_poll.c  mailbox poll loop (ipc_mailbox.c)

and of this file, which follows PDK code in ti/csl/arch/c7x/src:

  firmware/c71x/src/vectors.asm             event service table (Hwi_disp_always.asm)
